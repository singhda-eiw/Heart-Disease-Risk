# 《心跳的“预警”》——心脏性猝死风险因素分析

> 2026年计算机设计大赛 · 大数据应用主题赛

## 📌 项目简介
通过大数据分析方法，探究年轻人心脏性猝死的主要风险因素，并提出有关的预防建议。本研究分为四个维度展开。维度一采用XGBoost机器学习模型，量化8个风险因素对死亡率的贡献度；维度二采用相关性分析和分组对比，揭示睡眠不足与心脏健康的关系；维度三采用时间序列趋势分析，评估中国卫生资源配置；维度四采用聚类，年龄分层和指标对比，识别年轻人心脏病的核心风险因素。
